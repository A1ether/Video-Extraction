音频与文字稿

本地转录需要一个可选依赖（离线、不上传任何内容）：uv sync --extra transcribe， Apple Silicon 走 mlx-whisper。首次转录会下载模型权重（默认 large-v3-turbo 约 1.6GB）。

进度推送

默认开启，进度是推送过来的；若你所在网络/代理会打断长连接（表现为进度不走、状态卡住），关掉它即改为每 3 秒轮询。 也可以在地址上加 ?live=0 临时关掉（脚本化场景有用）。

怎么用

  1. 把分享链接贴进「提取」，点解析，确认标题/作者/码流没错。
  2. 选产物模式：视频（可选清晰度）/ 仅音频（m4a·mp3·flac，可勾本地转录）/ 图集（图文作品，下载成同名文件夹）。
  3. 可改文件名与输出目录，点下载。
  4. 在「任务」里看实时进度；B站/YouTube 有「合并」阶段，仅音频有「转码」「转录」阶段。
  5. 完成后可直接在页面里播放、看文字稿、打开图集、下载文件或在访达中定位。
