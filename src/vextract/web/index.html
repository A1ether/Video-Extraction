进度推送

默认开启，进度是推送过来的；若你所在网络/代理会打断长连接（表现为进度不走、状态卡住），关掉它即改为每 3 秒轮询。 也可以在地址上加 ?live=0 临时关掉（脚本化场景有用）。

怎么用

  1. 把分享链接贴进「提取」，点解析，确认标题/作者/码流没错。
  2. 选清晰度（默认最高），可改文件名与输出目录，点下载。
  3. 在「任务」里看实时进度；B站/YouTube 会有「合并」阶段（ffmpeg 无损合并音视频）。
  4. 完成后可直接在页面里播放、下载文件或在访达中定位。
